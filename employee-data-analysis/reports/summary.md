# Employee Data Analysis – Final Report

## 1. Problem Statement
The objective of this project is to analyze employee data and understand workforce distribution, salary patterns, and employee-related trends using Python.

## 2. Dataset
- Dataset: IBM HR Analytics Employee Attrition Dataset
- Total employees: 1,470
- Tools: Python, Pandas, NumPy, Matplotlib and Seaborn.

## 3. Three Key Insights
1. Department-wise analysis helps identify employee distribution across different departments.
2. Salary analysis helps compare average salary across departments and job roles.
3. Employee attrition analysis helps identify workforce retention patterns.

## 4. Recommendations
1. Improve employee engagement and career development opportunities to support employee retention.
2. Monitor department-wise salary distribution and workforce trends to improve HR planning.

## 5. Limitations
- Analysis is based on a single dataset.
- Results may not represent all organizations.
- Correlation does not necessarily indicate causation.

## Conclusion
The project demonstrates how Python data analysis and visualization can support better HR decisions through data-driven insights.
